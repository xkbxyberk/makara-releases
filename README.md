# Makara

Yerel çalışan bir macOS medya iş istasyonu. macOS 14 veya üstü, Apple silicon ve Intel.

**[Son sürümü indir](https://github.com/xkbxyberk/makara-releases/releases/latest)**: `Makara-….dmg`
dosyasını aç, Makara'yı Uygulamalar klasörüne sürükle, ilk açılışta **Kur** düğmesine bas.

Bu repo yalnızca yayınları taşır:

- `v…` sürümleri: imzalı ve notarize edilmiş DMG ile uygulamanın güncelleme akışı (`appcast.xml`).
- `runtime-…` sürümleri: kurulum sihirbazının indirdiği FFmpeg, Deno ve aria2 paketleri. Lisansları
  ve kaynakları paketlerin içinde (`LICENSES/`, `SOURCES.md`).

Kaynak kod: [xkbxyberk/makara](https://github.com/xkbxyberk/makara)
